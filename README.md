## Installer Sword en 3 minutes

Aucune connaissance en informatique n'est nécessaire.

1. **Téléchargez** le fichier en cliquant sur le lien ci-dessus : **[Télécharger Sword](https://github.com/pixl27/Telecharger-Sword/releases/latest/download/Installer-Sword.exe)**.
2. **Ouvrez-le** : dans votre dossier **Téléchargements**, double-cliquez sur **`Installer-Sword.exe`**.
3. **Si Windows affiche un écran bleu « Windows a protégé votre ordinateur »**, c'est normal pour une application récente :
   cliquez sur le petit texte **« Informations complémentaires »**, puis sur **« Exécuter quand même »**.
4. **C'est fini.** L'installation se fait toute seule en quelques secondes, puis Sword s'ouvre.
   Une icône **Sword** apparaît sur votre bureau et dans le menu Démarrer.

Aucun compte à créer et aucun réglage à faire : cherchez un film, une série ou un animé, et lancez-le.

> Si votre navigateur (Chrome, Edge) dit que le fichier « n'est pas couramment téléchargé » : cliquez sur **…** à côté du fichier, puis **Conserver** et **Conserver quand même**.

## Ce que fait Sword

- 🔎 **Une recherche, trois sites** : tous les résultats arrivent en direct.
- ▶️ **Reprenez où vous en étiez** : la rangée « À suivre » garde votre place, épisode par épisode.
- ⏭️ **Passez le générique**, d'un clic ou automatiquement.
- ⬇️ **Téléchargez des saisons entières**, puis regardez-les **sans connexion**.
- 🔔 **Nouvel épisode ?** Vos séries suivies vous préviennent dès qu'un épisode sort.
- 🍿 **Pas d'idée ce soir ?** Dites combien de temps vous avez : Sword propose trois séances.
- 🎞️ VF et VOSTFR, sous-titres .srt, jusqu'en 1080p, NVIDIA RTX Video.

## Questions fréquentes

**C'est payant ?**
Non, Sword est gratuit.

**Où vont les épisodes téléchargés ?**
Dans le dossier **Téléchargements** de votre PC. Vous pouvez le changer dans **Réglages**.

**Un site ne répond pas ?**
Sword passe automatiquement par un autre chemin. Une recherche peut alors prendre quelques secondes de plus.

**Comment désinstaller Sword ?**
Ouvrez **Paramètres Windows → Applications → Applications installées**, cherchez **Sword**, puis cliquez sur **…** et **Désinstaller**.
